เครื่องมือที่ใช้จริง

ทุกอย่างในลิสต์นี้คืออุปกรณ์และโปรแกรมที่ใช้งานจริง ไม่ใช่แค่แนะนำตามกระแส

PuTTY / OpenSSH

SSH client หลักที่ใช้ทุกครั้ง — ใช้ Windows ก็ PuTTY, Linux/Mac ก็ built-in ssh

WinSCP

ลาก-วาง firmware ข้ามไปเราเตอร์ผ่าน SCP — ง่ายกว่าพิมพ์ scp command มาก

Wireshark

ใช้ดัก packet เวลา reverse engineer API เราเตอร์ ISP หา endpoint ซ่อน

Python 3

รัน exploit script ต่างๆ — xmir-patcher, zte-config-utility ล้วนเขียนด้วย Python

CH341A Flash Programmer

ซื้อตัวนี้ไว้ก่อนเลย — ถ้า brick จนบูตไม่ขึ้น มีตัวนี้กู้ได้เกือบทุกกรณี

OpenWrt Firmware Selector

เลือก firmware ถูกรุ่น ถูก version — อย่า flash image มั่วๆ จากที่อื่น
